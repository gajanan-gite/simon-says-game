# Simon Game

A web-based implementation of the classic **Simon Game**, built using **HTML, CSS, JavaScript, and jQuery**.

## 🚀 Features

* Random color sequence generation
* User input validation
* Increasing difficulty with each level
* Sound effects and button animations
* Game over detection and restart functionality

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* jQuery

## 📚 Learning Purpose

This project was built while following a **Full-Stack Web Development** course on Udemy. It was created to practice:

* DOM Manipulation
* Event Handling
* Functions and Logic Building
* Arrays
* Game State Management
* jQuery

## ▶️ How to Run

1. Clone this repository.
2. Open `index.html` in your browser.
3. Press any key to start the game.
